# Predictive Sales Dashboard

Interactive sales analytics dashboard by AIMMS Consulting.

**Live:** https://sohail8850.github.io/aimms-consulting/dashboards/predictive-sales/

## Contents

| File | Purpose |
|------|---------|
| `index.html` | Self-contained dashboard (Chart.js via CDN, data embedded) |
| `Predictive_Sales_Data.csv` | Source data, 9,251 daily records |
| `Predictive_Sales_Dataset.ipynb` | Analysis notebook |

## Key insights

- Discounts cut revenue per sale by about 30% without lifting units sold.
- Revenue is flat, with no trend or seasonality.
- Categories are balanced, so gains come from pricing and discount policy, not mix.
- Customer rating has no link to revenue.
